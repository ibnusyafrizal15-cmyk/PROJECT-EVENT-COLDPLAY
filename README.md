## 📋 Deskripsi Proyek

Landing page interaktif untuk event konser **Coldplay – Music of the Spheres World Tour 2026** di GBK Jakarta. Proyek ini dibangun sebagai website event resmi yang menampilkan informasi lengkap konser, lineup artis, countdown timer, rundown acara, harga tiket, galeri foto, dan form registrasi.

Didesain dengan pendekatan **pure HTML/CSS/JavaScript** tanpa dependency eksternal — memastikan performa cepat, SEO-friendly, dan fully responsive di semua perangkat.

---

## 🚀 Fitur Utama

| Fitur | Deskripsi |
|---|---|
| 🎯 **Hero Section** | Animasi orbit dinamis dengan visual cosmic atmosphere |
| 👥 **Artist Lineup** | Grid card artis: Coldplay, Beyoncé, BTS, The Chainsmokers |
| ⏱️ **Countdown Timer** | Real-time JavaScript countdown menuju hari konser |
| 📅 **Show Rundown** | Timeline visual jadwal acara dari gate open hingga closing |
| 🎟️ **Ticket Pricing** | 3 tier tiket: Festival · Cat 1 · VIP dengan pricing detail |
| 🖼️ **Photo Gallery** | Lightbox gallery interaktif dengan caption overlay |
| ❓ **FAQ Accordion** | Dropdown FAQ accordion dengan smooth animation |
| 📝 **Register Form** | Form dummy pendaftaran tiket dengan validasi |
| 📱 **Responsive Navbar** | Hamburger menu untuk mobile dengan smooth toggle |
| 🌟 **Glassmorphism UI** | Desain modern dengan efek glassmorphism & glow |

## 📦 Cara Menjalankan

### 1. Clone Repository
```bash
git clone https://github.com/ibnusyafrizal15-cmyk/PROJECT-EVENT-COLDPLAY.git
cd PROJECT-EVENT-COLDPLAY
```

### 2. Buka di Browser
Tidak perlu server atau instalasi apapun — cukup buka `index.html` langsung di browser:

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 3. Atau Gunakan Live Server (VS Code)
Install ekstensi **Live Server** di VS Code, klik kanan `index.html` → **Open with Live Server**
